
# Customer Relationship Management System (CRM)

A Java-based application for managing customer records and tracking customer interactions, backed by an SQLite database.

## Overview

The Customer Relationship Management (CRM) System is a software project designed to organize customer information and maintain records of customer interactions.

The project demonstrates object-oriented programming, relational database integration, and structured software development using Java and SQLite.

## Technologies

- Java
- SQLite
- SQL
- Object-Oriented Programming (OOP)
